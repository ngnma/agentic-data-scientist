# 📊 Datasets Overview

This folder contains a collection of datasets used for testing and evaluating the Agentic Data Scientist pipeline.

---

## 🎵 Spotify Music Dataset
- **Source:** https://www.kaggle.com/datasets/anbudanadithya/spotify-music  
- **Description:** Contains metadata and audio features of Spotify tracks such as tempo, energy, genre, and popularity.  
- **Summary:** Music classification dataset with high-cardinality categorical features.  
  Useful for multiclass classification and encoding strategies.

---

## 🧠 Teenager Mental Health Dataset
- **Source:** https://www.kaggle.com/datasets/algozee/teenager-menthal-healy  
- **Description:** Data related to teenagers’ mental health, lifestyle, and behavioral factors.  
- **Summary:** Behavioral dataset for classification/regression tasks.  
  Useful for studying psychological and lifestyle impact patterns.

---

## 🎓 Student Academic Performance Dataset
- **Source:** https://www.kaggle.com/datasets/mubashirsidiki/student-academic-performance-500-students  
- **Description:** Contains academic records and demographic features of students.  
- **Summary:** Educational dataset for predicting student performance.  
  Useful for classification and feature importance analysis.

---

## 🍫 Chocolate Sales Dataset (2023–2024)
- **Source:** https://www.kaggle.com/datasets/ssssws/chocolate-sales-dataset-2023-2024  
- **Description:** Sales data including product, revenue, and time-based features.  
- **Summary:** Time-aware dataset for regression and trend analysis.  
  Useful for business analytics and forecasting.

---

## 🤖 AI Impact on Job Sector Dataset
- **Source:** https://www.kaggle.com/datasets/sumeakash/ai-impact-on-job-sector  
- **Description:** Dataset exploring how AI affects employment across industries.  
- **Summary:** Socio-economic dataset for classification/regression tasks.  
  Useful for studying AI adoption impact on jobs.

---

## 🏏 IPL Complete Dataset (2008–2025)
- **Source:** https://www.kaggle.com/datasets/meruvakodandasuraj/ipl-complete-dataset-2008-2025-enhanced-edition  
- **Description:** Comprehensive dataset of IPL matches, teams, and player statistics over time.  
- **Summary:** Sports analytics dataset with rich historical data.  
  Useful for predictive modelling and performance analysis.

---

## ☄️ NASA Near-Earth Objects Dataset
- **Source:** https://www.kaggle.com/datasets/darkmatternet/nasa-near-earth-asteroids-and-close-approaches  
- **Description:** Information about asteroids, including size, velocity, and close approach details.  
- **Summary:** Scientific dataset for classification and anomaly detection.  
  Useful for risk prediction and exploratory analysis.

---

## 📱 Mobile Price Classification Dataset
- **Source:** https://www.kaggle.com/datasets/iabhishekofficial/mobile-price-classification  
- **Description:** Features of mobile phones such as RAM, battery, and connectivity used to predict price range.  
- **Summary:** Structured classification dataset with numeric features.  
  Useful for benchmarking ML models on tabular data.

---

## 🚢 Titanic Dataset
- **Source:** https://www.kaggle.com/datasets/yasserh/titanic-dataset  
- **Description:** Passenger data from the Titanic disaster including age, gender, class, and survival outcome. 
- **Summary:** Classic binary classification dataset widely used in ML.  
  Useful for learning preprocessing, feature engineering, and model evaluation.

---

## Notes
- All datasets are sourced from Kaggle and may require proper citation when used.
- These datasets span multiple domains including music, education, business, healthcare, sports, and science.
